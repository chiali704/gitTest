14天夢幻藍圖

我們將採取冬季最具挑戰性也最具魅力的「逆時針自駕大環島」路線。跨越一號公路，環繞冰島一整圈（約 1,363 公里），深入冰雪與極光的世界。

裂縫浮潛

史費拉裂縫 3小時極致透明雙板塊浮潛。

雪地摩托車

布魯基地出發，馳騁於無垠冰川上的極速冒險。

雙冰洞探險

深入卡特拉與瓦特納藍黑冰洞，探索水晶宮殿。

極光溫泉

於米湖、藍湖、Vök地熱溫泉中漂浮靜候綠光。

雪橇犬體驗

在北方雪原與雪橇犬並肩前進，感受冰島冬日的速度與溫度。

冰島馬體驗

騎乘溫馴的冰島馬穿越雪地，認識獨特的 tölt 步伐。

每日行程

3/1DAY 00・出發日

路線台中 → 桃園國際機場 → 搭機前往冰島

18:45–19:00從台中出發，前往桃園機場。
21:00抵達桃園國際機場，辦理報到與安檢。
00:20起飛，航程約 9 小時 55 分，抵達冰島當地時間約 06:15。
08:30轉機／休息後，再接續前往冰島的後續安排。
目的地：桃園機場 → 冰島
🚗 台中出發✈ 搭機出發
3/2DAY 01・抵達西南部

路線機場 → 桑德格迪 → 雷克雅內斯半島

抵達後機場取車、採買補給，前往住宿辦理入住。
晚間視天氣狀況安排第一晚極光觀測。
住宿：桑德格迪小屋酒店
🚗 取車・補給✦ 極光初體驗
3/3DAY 02・黃金圈

路線桑德格迪 → 辛格維利爾國家公園 → 黃金瀑布 → 塞爾福斯

08:30–10:00前往辛格維利爾，車程約 1 小時 30 分。
10:30–13:30史費拉裂縫浮潛，含報到與裝備時間。
14:15–15:35辛格維利爾教堂、海菲特瀑布與 Öxarárfoss。
16:35–19:20黃金瀑布、間歇泉與 Strokkur，晚餐後前往住宿。
住宿：塞爾福斯 The Old farm house in Iceland
✦ 史費拉裂縫浮潛🍽 黃金圈晚餐
3/4DAY 03・南岸海景（1）

路線塞爾福斯 → 艾雅菲拉冰川 → Dyrhólaey → 雷尼斯黑沙灘 → 教堂鎮

08:15–09:45前往南岸，車程約 1 小時 30 分。
09:45–13:10Brú Base Camp 雪地摩托車體驗，含報到與裝備。
13:10–15:10午餐與南岸瀑布停留。
15:50–19:45黑沙灘、雷尼斯石柱與教堂鎮，車程約 1 小時 20 分。
住宿：教堂鎮 Eldhraun Holiday Home
✦ 雪地摩托車✦ 黑沙灘
3/5DAY 04・南岸海景（2）

路線教堂鎮 → 冰河湖 → 卡特拉冰洞 → 黑沙灘 → 教堂鎮

08:30–12:50冰河湖與鑽石沙灘，往返車程與拍攝停留約 4 小時。
12:50–15:20午餐、黑沙灘與南岸景點。
15:50–16:40黑冰洞／卡特拉冰洞導覽。
18:40–19:20返回住宿，晚餐與休息。
住宿：教堂鎮 Eldhraun Holiday Home
✦ 卡特拉冰洞🍽 南岸晚餐
3/6DAY 05・東南部

路線教堂鎮 → 傑古沙龍冰河湖 → 鑽石沙灘 → 赫本

07:40–14:15前往冰河湖，車程與沿途停留約 6 小時 35 分。
14:15–16:45傑古沙龍冰河湖與鑽石沙灘。
17:00抵達赫本、辦理入住。
19:10–21:00前往 Pakkhús 用餐，建議提前訂位。
住宿：赫本鎮霍芬旅館
✦ 傑古沙龍冰河湖🍽 Pakkhús 龍蝦餐廳
3/7DAY 06・東峽灣

路線赫本 → 東峽灣 → 埃伊爾斯塔濟 → Vök Baths

08:30–12:00沿東峽灣前進，車程約 3 小時 30 分。
12:00–15:30沿途海岸、漁村與 Egilsstadir 補給。
16:00–17:15入住並前往 Vök Baths。
17:30–20:00溫泉放鬆與晚餐。
住宿：埃伊爾斯塔濟美吉里度假屋
✦ Vök Baths 溫泉✦ 東峽灣海景
3/8DAY 07・東北部

路線埃伊爾斯塔濟 → 黏土沸泥區 → 火山口 → 米湖

08:00–11:00前往米湖，車程約 2 小時 30 分。
11:25–14:00地熱與火山地形景點，停留約 2 小時 30 分。
14:00–16:45前往 Vogafós 農場與米湖周邊。
17:10入住景觀別墅，晚餐後休息。
住宿：米湖 Svartaborg
✦ 米湖地熱景觀♨ 景觀 Hot Tub
3/9DAY 08・北部（鑽石圈）

路線米湖 → Grjótagjá 洞穴 → 黏土沸泥 → Goðafoss → 阿克雷里

09:00–13:10洞穴、火山地形與地熱景點，含拉車約 1 小時。
13:45–16:45Goðafoss 瀑布與北部沿岸景色。
18:30–20:30阿克雷里晚餐與市區散步。
住宿：阿克雷里 Thingvallastræti
✦ Goðafoss 瀑布🍽 阿克雷里晚餐
3/10DAY 09・北境探索

路線阿克雷里 → Go Husky → 市區 → Polar Hestar → Forest Lagoon

09:10–12:00前往 Go Husky，雪地活動與狗狗互動。
12:30–13:00午餐與市區補給。
13:50–16:00冰島馬體驗，含報到與騎乘時間。
17:30–20:00Forest Lagoon 溫泉與晚餐。
住宿：阿克雷里 Thingvallastræti
✦ 雪橇犬體驗✦ 冰島馬體驗🍽 Forest Lagoon 晚餐
3/11DAY 10・保留日

路線阿克雷里 → 西北部海岸 → 布魯迪歐斯

上午保留彈性，依天候安排市區散步、植物園或咖啡店。
16:30–18:30沿一號公路前往布魯迪歐斯，車程約 2 小時。
晚間入住後休息，整理隔日西部行程。
住宿：布魯迪歐斯 Blönduós 住宿
🚗 北部海岸拉車✦ 彈性備案日
3/12DAY 11・西北部補給站

路線布魯迪歐斯 → 布雷迪灣 → 赫倫瀑布群 → 博加內斯

上午西北部海岸景色與小鎮停留。
11:10–15:10沿途瀑布、教堂與 Hraunfossar 景點。
15:15–18:30Deildartunguhver 溫泉眼與 Krauma 溫泉。
19:15–21:00博加內斯晚餐，先確認餐廳營業時間。
住宿：博加內斯霍爾特度假屋
✦ Hraunfossar 瀑布♨ Krauma 溫泉🍽 博加內斯晚餐
3/13DAY 12・斯奈山半島

路線博加內斯 → Ytri Tunga → 黑教堂 → Kirkjufell → 斯奈山半島 → 雷克雅維克

07:50–10:15沿海岸前進，車程約 2 小時 30 分。
10:35–13:50海豹沙灘、黑教堂、草帽山與周邊景點。
14:50–16:50斯奈山半島午餐與回程拉車。
傍晚抵達首都，辦理入住。
住宿：雷克雅維克市區住宿
✦ 斯奈山半島✦ Kirkjufell 草帽山
3/14DAY 13・首都慢遊

路線雷克雅維克市區 → 藍湖 → 雷克雅維克

10:00–11:30哈爾格林姆教堂與市區散步。
11:30–13:30彩虹街、港口與市中心採買。
13:30–16:30市區午餐、咖啡與伴手禮。
16:30–19:15前往藍湖，泡湯約 2 小時，返回首都。
19:15–21:00旅程最後聚餐與整理行李。
住宿：雷克雅維克市區住宿
✦ 藍湖溫泉✦ 首都市區散步🍽 旅程收官晚餐
3/15DAY 14・返程

路線雷克雅維克 → 機場 → 回家

09:30退房、確認行李與租車還車時間。
09:20–11:30前往機場，預留約 2 小時拉車與還車。
11:45機場報到、午餐與免稅店採買。
12:30前往登機門，結束冰島旅程。
